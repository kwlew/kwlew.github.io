Install

  • 1. Drop Haven-<version>.jar into plugins/.
  • 2. Start the server. config.yml and messages.yml are generated on first run.
  • 3. Grant any additional permissions you need. The basic commands are available to everyone by default.

Runs on Paper 1.18.2 through 26.3: Java 17 for 1.18 to 1.19, Java 21 for 1.20 to 1.21.11, Java 25 for 26.1 to 26.3. PlaceholderAPI is optional.

Commands

CommandDescriptionPermission
/sethome [name]Saves a home at your location. Defaults to home. Run it again to confirm an overwrite.haven.sethome
/home [name]Teleports to a home. With no name, it uses a home called home, your only home, or shows your home list.haven.home
/delhome <name>Deletes a home and shows its coordinates. Alias: /removehome.haven.delhome
/homesLists your homes, grouped by world. Click a name to teleport. Alias: /listhomes.haven.homes
/haven reloadReloads config.yml and messages.yml.haven.admin.reload

Home names must be 1 to 16 characters long and can contain English letters, digits, - and _. Names are case insensitive.

Permissions

NodeDescriptionDefault
haven.homeUse /homeeveryone
haven.sethomeUse /sethomeeveryone
haven.delhomeUse /delhomeeveryone
haven.homesUse /homeseveryone
haven.homes.<n>Sets the home limit to <n>. Highest granted value wins.none
haven.homes.unlimitedRemoves the home limitop
haven.bypass.warmupTeleport instantlyop
haven.bypass.cooldownTeleport without waitingop
haven.admin.reloadUse /haven reloadop

For example, give members haven.homes.5 and donors haven.homes.15. Players without a limit permission use homes.default-limit from the config. If you lower a player's limit, their existing homes remain available; they cannot create another home until they are below the new limit.

config.yml

Covers home limits, the warmup and cooldown, storage, and sounds. Every option is commented in the generated file. The defaults:

homes:
  default-limit: 3              # limit without any haven.homes.<n>
  confirm-timeout-seconds: 15   # how long a /sethome overwrite stays confirmable

teleport:
  warmup-seconds: 3             # 0 for instant; bypass with haven.bypass.warmup
  cooldown-seconds: 10          # 0 to disable; bypass with haven.bypass.cooldown
  cancel-on-move: true          # moving to another block cancels the warmup
  cancel-on-damage: true        # fully absorbed damage does not count

storage:
  shutdown-timeout-seconds: 10  # how long shutdown waits for pending writes

sounds:
  enabled: true                 # master switch for every sound

Homes store their world by name, which keeps the files readable and hand-editable. Renaming or deleting a world orphans the homes saved in it: they stay on disk, and /home reports the world as missing instead of sending the player somewhere else.

Sounds

Each sound event has a namespaced key, volume, pitch and source. Custom resource pack sounds work too. Set a key to "" to silence one event, or set sounds.enabled: false to turn off all sounds.

EventPlays when
home-setA home was saved or moved
home-deletedA home was deleted
warmup-tickOnce a second while a teleport warmup counts down
teleport-successThe teleport landed
teleport-cancelledThe warmup was interrupted by moving or taking damage
deniedA command was refused: limit reached, on cooldown, or no such home

messages.yml

Command and teleport feedback lives in messages.yml in MiniMessage format. Setting a message to "" silences it. Run /haven reload to apply changes without restarting. Bukkit handles command permission denials before Haven receives the command.

PlaceholderAPI

Install a PlaceholderAPI build compatible with your Paper version to use these placeholders. The player must be online.

PlaceholderResult
%haven_homes_used%Homes currently saved
%haven_homes_max%Their limit (∞ when unlimited)
%haven_homes_free%Remaining slots
%haven_homes_list%Comma-separated home names

Storage

Haven stores one YAML file per player in plugins/Haven/homes/<uuid>.yml. You can edit these files while the server is stopped. Writes run on a background thread and are atomic, so a crash during a save cannot truncate a player's homes.
