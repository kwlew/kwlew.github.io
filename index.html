  1. 01

    kMoney

    An economy plugin for Paper 1.21+, compatible with Vault and PlaceholderAPI. Balances sit in a write-back cache flushed to disk off the main thread, the leaderboard rebuilds asynchronously, and money checks are guarded against duplication through hoppers, trades and bartering.

    Java / Paper / Open source -- downloads
    Plugin Docs Modrinth ↗
  2. 02

    Haven

    A homes plugin for Paper 1.18.2 to 26.3, a range spanning Java 17 to 25. Named homes, per-rank limits and a teleport warmup that cancels on movement or damage. Each player's file is written atomically on a background thread, so a crash never leaves one half-written.

    Java / Paper / Open source last push --
    Plugin Docs GitHub ↗
  3. 03

    Starsown

    A 2D top-down survival game, still a work in progress, built with LÖVE2D. Running copies report heartbeats and star counts to an API I run, which serves the live numbers in the Live section.

    Lua / LÖVE2D / Open source -- online · v--
