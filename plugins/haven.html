Haven

A homes plugin with a warmup that cancels when you move.

Named homes, per-rank limits, and a teleport warmup that stops the moment a player moves or takes damage. Every player's homes are saved to their own file, written so that a crash can never cut one short.

Features

8 in the box
Named homes
Saved with /sethome [name] and listed by world with /homes.
Per-rank limits
Set through haven.homes.<n>; the highest granted value wins.
Warmup
A teleport warmup that cancels if the player moves or takes damage.
Cooldown
A cooldown between successful teleports; a cancelled warmup costs nothing.
Overwrites
Replacing a home asks for confirmation, so one is never overwritten by accident.
Messages and sounds
Every message in MiniMessage format, every sound configurable.
Placeholders
PlaceholderAPI placeholders for home counts and names.
Storage
One YAML file per player, written atomically on a background thread.
