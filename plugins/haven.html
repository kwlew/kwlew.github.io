Haven

A homes plugin for Paper

Named homes, per-rank limits, and a teleport warmup that cancels when a player moves or takes damage.

Source code Documentation
Stars: loading Release: loading

Features

  • Named homes, saved with /sethome [name] and listed by world with /homes
  • Per-rank home limits through haven.homes.<n>, highest granted value wins
  • Teleport warmup that cancels if the player moves or takes damage
  • Cooldown between successful teleports; a cancelled warmup costs nothing
  • Overwrite confirmation, so a home is never replaced by accident
  • Every message in MiniMessage format, every sound configurable
  • PlaceholderAPI placeholders for home counts and names
  • One YAML file per player, written atomically on a background thread

Compatibility

Commands

CommandDescription
/sethome [name]Save a home at your location. Defaults to home.
/home [name]Teleport to a home.
/delhome <name>Delete a home and show its coordinates.
/homesList your homes, grouped by world. Click a name to teleport.
/haven reloadReload config.yml and messages.yml.

Permissions, configuration and placeholders are in the documentation.
