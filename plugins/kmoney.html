kMoney

A modern economy for Paper servers, Vault compatible out of the box.

Balances, payments, a rich list and physical money checks, with PlaceholderAPI support, configurable sounds and every message in MiniMessage.

CH.01

Features

Vault / PlaceholderAPI
Balances
Per-player balances stored in YAML behind an in-memory write-back cache.
Money checks
Withdraw balance into physical, tradeable in-game items and claim them with a right-click.
Leaderboard
An async rich list, /money top, with a configurable refresh interval.
Update checks
Admins get a join notice when a newer version is out on Modrinth.
Sounds
Every economy event plays a sound you can change or turn off in sounds.yml.
Messages
All text in messages.yml, written in MiniMessage.
Amounts
Shorthand input: 1k, 1m, 1b, 1t and on up to 1e72.

CH.03

Integrations

Works with
01

Vault

Registers as a Vault Economy provider, so any plugin that uses the Vault API works with kMoney balances out of the box.

02

PlaceholderAPI

%kMoney_balance%, %kMoney_balance_formatted% and %kMoney_symbol% for scoreboards, tab lists and chat.

CH.04

Under the hood

Java / Paper
Storage
One YAML file per player under plugins/kMoney/players/<uuid>.yml.
Cache
Reads are instant from memory; changed entries are flushed to disk every 30 seconds.
Threads
All leaderboard work runs asynchronously, so the main thread is never blocked.
Duplication
Money checks are protected against duplication through hoppers, villager trades and piglin bartering.
Config
Three files, config.yml, messages.yml and sounds.yml, all reloaded live.
