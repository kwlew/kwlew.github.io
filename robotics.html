ByteVoltaTeam / RoboCup Rescue Maze

Rescue Robotics

A robot that finds its own way through a maze nobody has shown it.

I program for ByteVoltaTeam, a four-person student team from Colégio Farias Brito in Fortaleza. Our robot took first place in every Rescue Maze category at the Brazilian championship in 2025, then placed 6th in the world at RoboCup 2026 in Incheon, Korea.

CH.01

The task

Zero human input

Rescue Maze stands in for a disaster site. The robot is placed in a maze it has never seen and has to explore it, find the victims and drop rescue kits beside them. Once the run starts, nobody controls it.

Unknown layout
The layout changes between rounds, so nothing can be hard-coded. The robot builds its map as it drives, across more than one level.
Victims
Each victim has to be identified, and the robot releases a rescue kit next to it.
Black tiles
Holes. The robot has to notice one, back out and never route through it again.
Blue tiles
The robot must stop and wait every time it enters one.
Ramps and debris
Ramps join the levels; debris and obstacles break up the straight runs.
Scoring
Points for tiles explored, victims found and the accuracy of the map.

CH.02

My part

C++ / RTOS

I write the robot's software in C++, mostly the parts that decide where it goes and how it goes.

01

Exploration

Deciding where to go next in a maze the robot has never seen: tracking which tiles are explored, picking the next unexplored one, and planning the route back to the start before time runs out.

02

Movement

Getting from one tile to the next: straight runs and accurate turns, driven by the gyroscope heading and the time-of-flight distance readings.

03

RTOS

Splitting the robot's work into real-time tasks, so sensor reads, movement and exploration decisions run side by side without blocking each other.

04

Optimization

Making all of it fast and reliable on embedded hardware: less time per tile, fewer wasted moves and more of the maze covered within the time limit.
